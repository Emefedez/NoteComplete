## What's new in 2.0.27

- **Word-by-word (`Ctrl + ←/→`) and line-start/end (`Alt + ←/→`) navigation & selection.** Hold `Shift` with `Ctrl + ←/→` to select word by word, or `Alt + Shift + ←/→` to select to the start/end of the line in any editable field (Notes, Markdown editor, Math Bar, text boxes) without triggering Back/Forward navigation.

Detailed change history: [CHANGELOG.md](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; `SHA256SUMS.txt` has the checksums. Not signed or notarized; see `docs/BUILDS.md`.
