## What's new in 1.2.60

- **Universal right-click translation, favorites, language search & Replace.** Right-clicking any highlighted text (in Markdown editor/preview, notes, PDF/OCR text layer, cards, chat, or text fields) now offers **Translate** with a favorite-languages submenu (**Español**, **English**, and **中文 (简体)** by default) plus **More languages…** to search 33+ languages and ★ star/unstar favorites. Inside the Translator, a **Replace** button replaces the selected editable text with the active translation. The Chinese Look up panel remains untouched for quick lookup and adds a **Translate** icon button plus default **radical & component meanings** in **Structure**.
- **Smarter, safer Chinese IME & synced Stroke order repeat.** Holding **Space** in both Hanzi and Pinyin modes no longer spams spaces; dead-key accents (`´` + `e` → `xué`) stay inside Chinese composition without dropping the pinyin buffer; **↑ / ↓ / ← / →** navigate the candidate popup with coherent 2D row/column wrapping; **Shift + 1–9** picks candidates 1–9 while composing without ever leaking `!`, `"`, `@` or toggling Latin mode; and typing `.` stays standard ASCII punctuation by default (full-width Chinese punctuation remains opt-in in Settings → Chinese). Stroke order loop toggles now only toggle the repeat state without restarting in-progress animations and stay 100% synchronized with Play/Pause (`paused` always stays paused).
- **Markdown split resize, independent Editor/Preview zoom, left Chinese controls & medallion double-click.** Added a draggable split divider between the Markdown editor and preview (double-click resets 50/50), independent zoom controls (`Edit` and `View` plus `Ctrl/⌘ + Wheel` over each pane), moved the Chinese controls (`中`, `拼`, `笔 Trace`) into the left dark-toggle slot in Markdown edit mode, enabled right-click Stroke order & Translate on Chinese characters/selections in Markdown, and made double-clicking Markdown prefab medallions open the Stroke order / prefab editor directly instead of a context menu.
- **Mobile web CSS-zoom drag & clamping fix.** Floating windows, toolbars, context menus, selection bars, and `#toolOptions` now divide viewport bounds and pointer deltas by the active CSS `zoom` factor so dragging works all the way to the bottom edge on mobile web.

Earlier versions: [changelog](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; SHA256SUMS.txt has the checksums. Not signed or notarized; see docs/BUILDS.md.
