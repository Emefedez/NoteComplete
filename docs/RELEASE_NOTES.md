## What's new in 2.0.24

- **Fixed horizontal toolbar expanding when popping the tool settings panel (e.g. pressing `P` twice).** Inline styles for `#toolOptionsMirror` now match its `data-mirror-id` descendants (`drawingOptions`, `selectionOptions`, `selectionFields`, `snapOptions`, `shapeOptions`, `shapePrefab`, color wheel, etc.), so opening the floating tool settings card keeps the horizontal toolbar at its exact compact single-row height.
- **Expanded Math Adaptation shorthands & cheat sheet** (sets & logic, `abs`/`floor`/`ceil`, upright math functions, `partial`/`nabla`, `~=`, `===`, `=/=`, `<>`, `-+`, `<<`, `>>`, `...`, `propto`), website welcome note removed, and refreshed README screenshots.

Detailed change history: [CHANGELOG.md](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; `SHA256SUMS.txt` has the checksums. Not signed or notarized; see `docs/BUILDS.md`.
