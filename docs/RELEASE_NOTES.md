## What's new in 2.0.32

- **Single-row draggable Notes (`N`) sidebar header & toolbar with edge fades.** Reorganized the Notes sidebar actions (`+ Page`, `Preview`, `Follow`, `中`/`笔`, `?`) into a clean single-row click-and-drag scrollable strip with dynamic left/right fade masks (and `×` always pinned at the rightmost edge), plus made the Markdown command bar below it a single-row draggable fading strip too so neither ever wraps into two rows.

Detailed change history: [CHANGELOG.md](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; `SHA256SUMS.txt` has the checksums. Not signed or notarized; see `docs/BUILDS.md`.
