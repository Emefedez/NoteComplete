## What's new in 2.0.23

- **Expanded Math Adaptation shorthands & cheat sheet.** Added sets & logic (`forall`/`paratodo`, `exists`/`existe`, `isin`/`pert`/`in RR`, `notin`, `emptyset`/`vacio`, `union`/`cup`, `inter`/`cap`, `subset`/`subseteq`, `RR`/`NN`/`ZZ`/`QQ`/`CC`), `abs()`/`floor()`/`ceil()`, upright math functions (`ln`, `log`, `sin`, `cos`, `tan`, `exp`), `partial`/`nabla`, and operators (`===`, `=/=`, `<>`, `-+`, `<<`, `>>`, `...`, `propto`) — all searchable in the bilingual cheat sheet.
- **Removed the website welcome note.** The web app now opens directly on Home.
- **Refreshed README & modern screenshots** and fixed the CI regex test for the multi-row selection bar.

Detailed change history: [CHANGELOG.md](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; `SHA256SUMS.txt` has the checksums. Not signed or notarized; see `docs/BUILDS.md`.
