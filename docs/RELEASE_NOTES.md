## What's new in 1.2.58

- **Mobile layout, dropdowns & Stroke order prefab fixes.** Eliminated double top safe-area padding inside the Android APK (`nc-native-app`), fixed lost bottom space when zooming out on mobile web (`calc(100dvh / var(--ui-zoom, 1))`), reparented and zoom-clamped mobile dropdowns (`File`, `Google Drive / Services`, Home filters, top bar menus, selects, and context menus) with automatic above/below flipping, and anchored phone prefab windows cleanly below `#commandBar` with compact mobile stroke squares so `Cancel / Insert` and `Show this step on the page` are always reachable.
- **Per-character stroke loop animations & Trace SVG language toggle.** Added a circular dotted repeat toggle in the top-right corner of every stroke square (lighting up in the accent color when active to loop that character independently) plus a toggle-all loop button in the player bar. Toggling `ES | EN` in the Stroke order prefab now immediately updates the Trace SVG preview and stores the chosen definition language in the inserted figure.
- **Smarter Chinese input (IME) & dictionary downloads.** Mid-syllable tone digits and accented vowels (`zho1ngwén`, `zhongwe2n`, `zh1ongwen`, `zhongwen`) now resolve directly to `中文` (including dead-key accents on Spanish/European keyboards), typos like `zhonwen`, `zhomgwen`, `nihoa`, and `xiexei` offer fuzzy similar-word matches (`≈`), holding **Space** in Hanzi mode no longer spams spaces (inserts one space on release if no digit/letter was pressed), digits typed before a complete syllable wait cleanly for the next letter, and the candidate popup stays above the font/format bar (`z-index: 200` + overlap avoidance). Added a **Dictionaries** download button in both Look up and Stroke order with HSK packs plus local dictionary import (CC-CEDICT `.u8`/`.txt`, JSON, TSV, CSV).
- **Accessible "Kept for exercises", Markdown toolbar order, US Favorites & Multi-OS Dropbox setup.** Added a floating **Kept for exercises** viewer reachable from **Study → Kept for exercises…**, a live **★ Kept (N)** top-bar pill, and a jump button inside the Chart editor. Reordered TinyMDE and Markdown toolbar icons into logical groups, standardized UI labels to **Favorites**, and expanded the **Dropbox setup guide** with step-by-step instructions, copyable commands, Device Setup Codes, and downloadable auto-setup scripts for Windows, macOS, Linux, Android, and iOS/iPadOS.

Earlier versions: [changelog](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; SHA256SUMS.txt has the checksums. Not signed or notarized; see docs/BUILDS.md.
