## What's new in 2.0.13

- **T3 Code integration & automatic AI harness failover for document generation.** Added **T3 Code** as a selectable AI harness (with 1-click cross-platform installer and automatic on-demand start / idle auto-close matching R Commander Studio). AI document generation now routes through T3 Code and automatically hands off the orchestrator chat and regenerates remaining subagents on the next harness in your **Harness failover priority** list (configurable in **Setup wizard → AI** and **Help → Connect AI tools…**) whenever a harness errors out or hits usage limits, without losing completed work.
- **Moodle Cloud section, UVIGO Moovi SAML2 SSO & Student Assistant sidebar.** Added **Moodle** to Home → Cloud and the Setup Wizard with a built-in **Moovi — Universidade de Vigo (UVIGO)** SAML2 SSO preset (plus custom Moodle servers & tokens). Browse courses, sections, folders, and resources directly inside NoteComplete, download individually or in bulk via the download queue, open the exact course/page in your browser, and use the **Moodle tools** sidebar for upcoming deadlines, grades, forums, Ask AI, and `open-moodle` / `moodle-student-bridge` MCP configs.
- **Global Home search bar.** Added a unified search bar at the top of the Home screen that searches across **Recent**, all currently enabled **Cloud** providers, and the currently chosen **Moodle** course at once, alongside the existing per-section search bars.

Detailed change history: [CHANGELOG.md](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; `SHA256SUMS.txt` has the checksums. Not signed or notarized; see `docs/BUILDS.md`.
