## What's new in 2.0.30

- **One-click paste AI-generated tables as Table prefabs.** Any table generated in Ask AI chat now has a **Paste as table prefab** button directly under it (plus a **Table prefab** button in the answer's action bar) that drops the table directly onto the current page as an editable Table prefab (preserving KaTeX `$…$` math in cells and cell merges) or pastes it into your Markdown notes.

Detailed change history: [CHANGELOG.md](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; `SHA256SUMS.txt` has the checksums. Not signed or notarized; see `docs/BUILDS.md`.
