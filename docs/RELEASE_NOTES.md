## What's new in 1.2.73

- **Sticky notes see-through on tap or right-click.** With the Pan tool, tap a sticky note to make it, and the ink and typed text written on it, see-through so the page underneath shows (as tape lifts); tap again to show it. Right-click (or hold) a sticky note, or ink or text on it, for **See through this sticky note** / **Show this sticky note**. Ink and text added after the page was drawn fade with the note too. The top strip toggle still works.
- **Sticky note titles no longer cut off.** The title's first line sat partly under the darker adhesive strip; it now clears it. Titles wrap by the width of their letters (wide letters such as W and M no longer run off the card, and other titles use the space they have), and a title longer than two lines ends in “…” instead of losing words.
- **More of `app.js` split out.** PDF zoom sharpening (`pdf-detail.js`), page list thumbnails (`page-thumbnails.js`), the Layers panel (`layer-panel.js`) and tool width presets (`tool-widths.js`) moved into their own modules: `app.js` is now 7,744 lines (from 10,074 two releases ago). No behaviour change.
- **Leaner reader code: `app.js` split into feature modules.** The reader's main script went from 10,074 to 8,269 lines: media opening (`media-open.js`), the Insert pages and Change PDF background dialogs (`page-dialogs.js`), pen button setup and pen test (`pen-setup.js`), pen hover preview and touch tooltips (`pen-hover.js`), graphs/tables/prefabs/UML and their editors (`figures.js`), item copy/cut/paste (`item-clipboard.js`), the item and page context menus (`item-menus.js`), and study material import (`study-import.js`) now live in their own modules. No behaviour change: the code moved verbatim and the app runs the same before and after.
- **Movable Math toolbar button, dedicated Math / R icons & Home filter bar spacing.** Fixed the Math toolbar button (`#mathModePill`) not being drag-reorderable with the rest of the toolbar tools, gave Math Mode its own distinct `∑` sigma icon instead of sharing the Prefabs graph icon, replaced the Math Mode bar's `+ Box`, `R Plot`, and `R Studio` buttons with dedicated icons (`mathBox`, `rplot`, `rstudio`), updated R Commander Studio menu/toolbar entries to use the R Studio circle-R icon, and removed the excess top gap above the Home filter bar (`Type`, `Modified`, `Source`, `Size`, `Favourites`, `Audio`) so it sits cleanly both unscrolled and when sticky.
- **Math Mode (`∑ Math` / `Ctrl+Shift+M`), R Statistics Prefabs & R Commander Studio Integration.** Added a toggleable Math Mode toolbar (top-bar `∑ Math` pill, `View → Math Mode`, `Ctrl+Shift+M`, and `View → Math Mode & R Bridge…`) featuring live KaTeX preview, built-in CSP-safe numeric & symbolic CAS (`=` evaluate with exact fractions & deg/rad, `d/dx` symbolic derivative, `∫` definite integral, `Solve` root finder), one-click **Plot** to Function Graph, **`+ Box`** Math Text Box insertion, and direct **R Commander Studio** launch. Added a new **Statistics & R** prefab module (`Shift+X`: Normal, Student *t*, Chi-squared, Binomial, Histogram + Density, Boxplot, Scatterplot + Fit, and Custom R) backed by the desktop R Bridge (`127.0.0.1` token-authenticated **R Commander Studio** connection with isolated local `Rscript` fallback); figures are strictly SVG-sanitized (inlining Cairo glyph references) and cached inside `.nfedit` with zero auto-execution on note open. NoteComplete can also automatically download and install **R Commander Studio** for supported platforms (Linux x64/ARM64 AppImage, Windows x64, macOS ARM64), create single `.R` / `.Rmd` files or full R Workspace folders from **File → New note…**, open `.R`, `.Rmd`, `.qmd`, and `.RData`/`.rds` files with live disk sync, and highlight `.Rmd`/`.qmd` `{r}` code chunks natively.
- **Goodnotes import visual quality & Sticky Note peek/hide.** Fixed Goodnotes highlighters rendering over black text (translucent strokes now import as multiply-blended highlighters sorted beneath opaque pen ink), restored Goodnotes 6 translucent shape fills (`0.18` alpha) on editable shapes, added quadratic midpoint stroke smoothing for crisp handwriting curves, upgraded Sticky Note rendering to 2×2 supersampled anti-aliased PNGs that properly cover background page strokes while keeping parented sticky strokes and repositioned author text on top, and added interactive **top-strip click-to-peek** on sticky notes that fades both the card and all ink/text owned by it to pseudo-transparent (`Show note` restores it).
- **Audio & video files added to Recent + Move to Trash from Home/Folders.** Fixed opened audio (`.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`, `.aac`, `.opus`) and video (`.mp4`, `.m4v`, `.webm`, `.mkv`, `.mov`, `.avi`, `.ogv`) files not being added to **Recent** and enabled moving local audio, video, and note files on disk to the system Trash directly from Home's `⋯` menu (both in Recent and inside opened Folders).
- **Zero-flicker PDF backgrounds & configurable PDF page preloading.** Cached PDF page rasters now attach synchronously on the same frame without waiting for `scrollPause` (eliminating white flash/flicker when scrolling), and **View → Display quality…** now includes a **Preloaded PDF pages** slider (`0–20`, default `2`, scaling both preload margin and LRU raster cache size) alongside a **Reset to default** button.
