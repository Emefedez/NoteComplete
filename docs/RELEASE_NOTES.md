## What's new in 1.2.67

- **Expanded document, presentation, spreadsheet, e-book & media support (converted to Markdown).** Added built-in Markdown converters for legacy Word (`.doc` via OLE2 piece tables plus RTF/HTML fallback), Rich Text (`.rtf`), PowerPoint (`.pptx`, `.pptm`, `.ppt`), OpenDocument Presentation (`.odp`), Flat OpenDocument (`.fodt`, `.fods`), legacy/macro/binary Excel (`.xls`, `.xlsm`, `.xlsb` via SheetJS core), EPUB e-books (`.epub`), Jupyter notebooks (`.ipynb`), and a built-in pure-JS OOXML `.docx`/`.docm`/`.dotx` fallback so Word documents open reliably even without mammoth. Also expanded image (`.gif`, `.bmp`, `.avif`, `.ico`), audio (`.mp3`, `.m4a`, `.wav`, `.ogg`, `.flac`, `.aac`, `.opus`), video (`.mp4`, `.mkv`, `.mov`, `.webm`, `.avi`, `.m4v`), and academic text (`.rst`, `.adoc`, `.org`, `.rmd`, `.qmd`) support across Home, folders, archives, cloud providers, and OS "Open with" handlers.
- **Crisp color-coded icons for audio, video, Office, EPUB & notebook cards.** `.mp3`, `.mp4`, other audio/video files, Word/ODT/RTF documents, spreadsheets, presentations, e-books, and Jupyter notebooks now display clean color-coded SVG icon covers (and `Audio` / `Video` badges and filters) on Home, Folders, Drive, Dropbox, GitHub, WebDAV, and Archives — generated instantaneously without reading large media files from disk.
- **Fixed middle-click (click wheel) creating spurious text boxes on Linux.** Pressing the mouse wheel to pan now blocks Linux primary-selection `mouseup`/`auxclick` `paste` events both on `#viewport` and globally on non-editable surfaces so wheel clicks never accidentally spawn a text box with previously typed/selected text.
- **Fixed stray `"false"` text in the Chinese selection toolbar.** Filtered falsy buttons before calling `replaceChildren` in `chinese/zh-select.js` so selecting a non-lookupable Chinese phrase no longer renders literal `"false"` between the Translate and Stroke order icons.
- **Sticky Note prefab & Goodnotes import overhaul.** Added an editable **Sticky note** prefab (`Shift+X` → Notes → Sticky note: colour swatches, custom colour picker, title, wrapped body text, footer/author, optional ruled lines and folded corner, drawn underneath handwriting so ink stays visible on top). Goodnotes `.goodnotes` and Notability `.ntb` imports now keep shapes as real editable/resizable NoteComplete shapes (instead of flattening them into highlighter-band groups), recognise rotated shapes and Goodnotes polygon rectangles over PDF pages without dropping fills or emitting warnings, fix Goodnotes 6 unfilled shapes being misread as opaque fills, import Goodnotes sticky notes as editable Sticky Note prefabs under handwriting, and show non-fatal import notices as normal status messages rather than red error toasts.

Earlier versions: [changelog](https://github.com/Emefedez/NoteComplete/blob/main/docs/CHANGELOG.md). Preview installers for Android, Linux (AppImage), macOS and Windows; SHA256SUMS.txt has the checksums. Not signed or notarized; see docs/BUILDS.md.
