# Skills

Claude Code skills that came out of building NoteComplete. They live here until they get a repository of their own.

- `polished-apps/` — stack, visual system, layout, interaction, AI and checks for lightweight, feature-rich desktop/web apps (NoteComplete is its worked example).

Install: link the folder into `~/.claude/skills/`, e.g. `ln -s "$PWD/skills/polished-apps" ~/.claude/skills/polished-apps`.
